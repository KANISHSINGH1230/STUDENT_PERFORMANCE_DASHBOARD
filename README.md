## 📊 Power BI Dashboard

An interactive **Student Performance Analytics Dashboard** built with **Microsoft Power BI** to analyze students' academic performance, attendance, and behavioral patterns.

The dashboard provides both **Academic View** and **Behavioral View**, allowing users to explore student-level insights through interactive filters, KPIs, charts, and detailed tables.

---

## 🚀 Project Overview

The objective of this project is to transform student academic and behavioral data into meaningful and easy-to-understand visual insights.

The dashboard helps answer questions such as:

* 📈 What is the overall average student score?
* 🎯 Which subjects have the highest average scores?
* 📚 How does student performance change across different terms?
* 🕒 What is the average attendance percentage?
* 👨‍🎓 How many students are included in the dataset?
* 🧠 What are the most common behavioral patterns?
* 🔍 How does an individual student's performance compare with others?
* 📋 What is the performance category of each student?

---

## 🖥️ Dashboard Views

### 1️⃣ Academic View

The Academic View focuses on student academic performance and attendance.

**Key KPIs:**

* 👨‍🎓 Total Students
* 📅 Average Attendance
* 📊 Average Score

**Visualizations:**

* Average Score by Subject
* Performance Trend by Term
* Student-wise Score Table
* Performance Category
* Student Status
* Interactive Filters

### 2️⃣ Behavioral View

The Behavioral View focuses on student attendance and behavioral patterns.

**Visualizations include:**

* Attendance Distribution
* Behaviour Type Distribution
* Student-wise Performance Details
* Performance Category
* Student Status

---

## 🎛️ Interactive Filters

The dashboard contains interactive slicers that allow users to analyze the data based on:

* **Class**
* **Subject**
* **Term**
* **Section**

These filters dynamically update the dashboard visuals and student-level information.

## 📌 Key Dashboard Insights

### 📚 Subject Performance

The dashboard compares average scores across:

* Mathematics
* Science
* English
* History
* Geography

This makes it easy to identify subjects where students are performing strongly or may require additional attention.

### 📈 Performance Trend

The Performance Trend by Term visual helps track how average student scores change across different academic terms.

### 🕒 Attendance Analysis

Average attendance provides an overview of student participation and helps identify attendance-related patterns.

### 🧠 Behaviour Analysis

The Behaviour Type Distribution visual provides insights into different student behavior categories, including:

* Disruptive
* Late
* Helpful
* Participative
* Absent Without Notice
